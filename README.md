# TimesheetManagerProj
A small timesheet manager program written in the Microsoft Visual Basic language. Current Functionality: Add Timesheet, Remove, Search, Display current timesheets.User can use the application to enter time shift details and add them to an array.  Remove a timesheet from the list, or search for an existing timesheet. Still in progress
